# Personal Library Manager 📚

## Overview
**Personal Library Manager** is a web application built using **Streamlit** that allows users to manage their personal book collection efficiently. With this app, users can add, edit, and track their books with ease.

## Features 🚀
- 📌 Add new books with details  
- 🔍 Search and filter books  
- 📖 Track reading progress  
- 🗑️ Delete or update book records  
- 📊 Visualize reading trends

## Installation & Usage 🛠️
To run this project locally, follow these steps:

### 1️⃣ Clone the repository
```bash
git clone https://github.com/your-username/personal-library-manager.git
cd personal-library-manager
```

### 2️⃣ Install dependencies
```bash
pip install -r requirements.txt
```

### 3️⃣ Run the application
```bash
streamlit run app.py
```
