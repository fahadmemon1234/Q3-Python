# 🌱 Growth Mindset Data Sweeper

### 🚀 Embrace the journey of data transformation!

Welcome to **Growth Mindset Data Sweeper**, an interactive web application built using **Streamlit** and **Pandas**. This tool allows users to upload CSV and Excel files, perform essential data cleaning, and download the refined dataset, all while fostering a growth-oriented mindset!

## ✨ Features
- **📁 Upload CSV & Excel Files** – Supports multiple file formats.
- **🔍 Quick Data Preview** – Get an instant glimpse of your dataset.
- **🧹 Data Cleaning Tools** – Remove duplicates and handle missing values.
- **📊 Data Insights** – View total rows, columns, and missing values.
- **💾 Download Enhanced Data** – Save cleaned data instantly.
- **🌟 Growth Mindset Encouragement** – Motivational tips throughout the process.

## 🛠 Installation & Usage

1. **Clone the Repository**
   ```sh
   git clone https://github.com/fahadmemon1234/Q3-Python.git
   cd Q3-Python
   ```
2. **Create a Virtual Environment (Optional but Recommended)**
   ```sh
   python -m venv venv
   source venv/bin/activate  # On macOS/Linux
   venv\Scripts\activate    # On Windows
   ```
3. **Install Dependencies**
   ```sh
   pip install -r requirements.txt
   ```
4. **Run the Application**
   ```sh
   streamlit run growth.py
   ```
5. **Open in Browser**
   - The application will open at: `http://localhost:8501`
